# URVION Volume 2

Standalone static event website for the Eco-Social Club, Silicon University, Bhubaneswar.

## Commands

- `npm run dev` — local preview at `http://localhost:4173`
- `npm run check` — syntax validation
- `npm run build` — creates deployable files in `dist/`

The authored site lives in `src/site/`. Only assets referenced by the live pages are kept in this project.
